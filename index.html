03

구성요소

  • 이름만 알면 충분

메인 보드

  • 육각 칸 = 화성 지도
  • 둘레 TR 트랙 · 좌 산소 · 우 온도
  • 아래 표준 프로젝트 · 마일스톤 · 어워드

개인 보드

  • 자원 6칸
  • 칸 위 = 생산량 (매 세대 수입)
  • 칸 아래 = 보유량 (지금 가진 것)

자원 큐브 (금속)

  • 동 1 · 은 5 · 금 10
  • 놓인 칸 = 자원 종류

프로젝트 카드

  • 왼쪽 위 숫자 = 가격 (M€)
  • 초록 · 파랑 · 빨강 (10장)

기업 카드

  • 내 회사 = 시작 자금 + 고유 능력
  • 게임 내내 앞에 펼침

타일

  • 바다 9개 · 주인 없음
  • 녹지 · 도시 + 내 큐브 = 소유

플레이어 큐브 (반투명)

  • TR · 생산량 · 타일 소유
  • 파란 카드 사용 · 마일스톤·어워드

흰 큐브 3개

  • 온도 · 산소 · 세대 표시

04

게임 준비 (2인)

  • 처음 = 입문 · 해봤음 = 표준
  • 체크하며 진행
    • 기업 시대 규칙 사용 시: 생산량 0에서 시작 + 기업시대 표시 카드 포함
    • 처음 두세 판은 미사용 권장
    05

    한 세대 = 4단계

    • 세대 = 라운드
    • 단계 클릭 또는 자동 재생
    06

    내 차례: 행동 1~2개

    • 차례마다 행동 1 또는 2개
    • 할 게 없음 → 패스 = 이번 세대 끝
    • 남은 사람은 혼자 계속 · 모두 패스 → 생산 단계
    카드값

    • 티타늄 1 = 3 M€ (우주 태그)

    • "행동:" 카드 = 세대당 1번

    • 파란 예약 칸만

    녹지

    • 예약 칸 X
    • 가능하면 내 타일 옆
    • 산소 +1 → TR +1 · 끝에 1 VP

    도시

    • 예약 칸 X
    • 도시끼리 인접 금지 (누구 것이든)
    • 끝에 옆 녹지 1개당 1 VP (남의 녹지 포함)
    • 모든 타일: 칸에 그려진 배치 보너스 획득
    • 모든 타일: 옆 바다 1개당 +2 M€

    글로벌 수치와 TR

    • ★ 칸 도달시킨 사람 → 추가 보너스

    온도 (°C)

    • ★ −24 · −20°C → 열 생산 +1
    • ★ 0°C → 바다 1개 배치 (그 바다로 TR +1 추가)

    산소 (%)

    • ★ 8% → 온도 +1칸 (그 온도로 TR +1 추가)

    TR

    • 시작 20
    • 수치 1칸 → +1
    • 수입 = TR + M€ 생산
    • 게임 끝 TR = VP

    최대치 도달 후

    • 그 수치 · TR 더 안 오름
    • 녹지는 계속 가능 (1 VP만)
    • 바다 9개 끝 → 바다 더 못 놓음

    자주 틀리는 것

    • 테이블 논쟁 시 여기부터
    1. 1세대 = 연구 단계 없음준비 때 카드 구매 완료 · 2세대부터 4장
    2. 에너지 = 다음 세대로 안 남음생산 단계에 전부 열
    3. 수입 = TR + M€ 생산TR 빼먹는 실수 최다
    4. 녹지 = 산소 +1 = TR +1식물 전환 · 표준 프로젝트 동일
    5. 바다 옆 = 1개당 2 M€바다를 바다 옆에 놓아도 받음
    6. 도시끼리 인접 금지상대 도시 옆도 금지
    7. 파란 카드 행동 = 세대당 1번카드 위 큐브 · 생산 단계 끝에 회수
    8. 패스 = 이번 세대 끝행동 1개 후 넘기기 ≠ 패스
    9. 철·티타늄 = 태그 일치 필요철 → 건물 · 티타늄 → 우주
    10. 빨강 이벤트 태그 = 이후 안 셈뒤집어 두기 때문 · 마일스톤 셀 때 주의
    11. 요구조건 = 낼 때만이미 낸 카드는 그대로 유지
    12. 2인 어워드 = 1등만후원은 내가 해도 1등이 상대면 상대 점수
